Fundamento

¿Qué es HTML?

HTML significa HyperText Markup Language y organiza el contenido que interpreta el navegador.

HTML sí es…

Un lenguaje de marcado. Sus etiquetas describen la estructura y el sentido del contenido de una página web.

HTML no es…

Un lenguaje de programación. Por sí solo no ejecuta funciones algorítmicas.

Información adicional

Atributos y valores

El atributo se escribe en la apertura, después del nombre de la etiqueta y antes de >.

<input type="text">
Conjunto finito: el atributo acepta una lista limitada de valores válidos.

Atributos comunes

AtributoValorDescripción
idnombreIdentificador único en la página.
classnombreClase que puede repetirse.
langidiomaIdioma conforme al código ISO 639-1.
translateyes | noIndica si el contenido es traducible.
titletítuloMensaje emergente al colocar el puntero.
styleestilosAplica propiedades CSS directamente.
✓
Convención recomendada: escriba los valores entre comillas dobles.

Bloques y sentido

div, semántica y Emmet

Un bloque organiza; una etiqueta semántica, además, comunica la función de esa zona.

Un bloque con <div>

<div style="border:1px solid #1769aa;
            width:45%; padding:12px;">
  Bloque de contenido
</div>

div define un bloque o sección al que se pueden aplicar estilos.

Mapa de una página

Estructura básica HTML5

<!DOCTYPE html>
<html>
  <head><title>Título de la página</title></head>
  <body>
    <header>Encabezado</header>
    <nav>Navegación</nav>
    <main><section>Contenido</section></main>
    <footer>Pie de página</footer>
  </body>
</html>
