1. Dos maneras de organizar una interfaz

HTML crea la estructura. CSS decide cómo se ve y cómo se distribuye. Flexbox y Grid son sistemas de CSS que trabajan sobre un contenedor y sus hijos directos.

Flexbox

Conviene cuando el problema principal es una fila o una columna: menús, botones, alineación, grupos de elementos.

.contenedor { display: flex; }

Grid

Conviene cuando necesitamos pensar en filas y columnas: galerías, catálogos, tableros y estructura general.

.contenedor { display: grid; }
Regla para comenzar: si piensa en una línea, pruebe Flexbox; si piensa en una cuadrícula, pruebe Grid. En una página real es normal usar ambos.

4. ¿Flexbox o Grid?

Seleccione la herramienta que utilizaría primero en cada situación. La respuesta no busca memorizar una frase, sino reconocer la estructura visual.

A. Una barra con Inicio, Cursos, Proyectos y Contacto en una sola fila.
B. Un catálogo de productos que debe verse en tres columnas.
C. Centrar un botón horizontal y verticalmente dentro de una caja.
D. Una página con barra lateral y contenido principal en columnas diferentes.
Importante: en varios casos ambos pueden funcionar. Aquí se elige la herramienta que resulta más natural para el problema descrito.

5. Ejemplo combinado

Grid puede definir la estructura grande de una página y Flexbox puede organizar los elementos internos de una zona.

Grid por fuera
.pagina { display: grid; grid-template-columns: 220px 1fr; gap: 16px; }
Flexbox por dentro
.encabezado { display: flex; justify-content: space-between; align-items: center; }
